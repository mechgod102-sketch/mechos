# MechOS v0.3.0 Hotfix 34 — MechScope responsive UI cleanup

Hotfix 34 is a visual-only cumulative update on top of Hotfix 33. It does not replace or redesign the HF33 source-owned MechScope runtime/session architecture.

## Fixed

- Explicit readable light colors for the MECHOS brand, MechScope hero title, hero copy and normal labels.
- Long GPU/system status strings stay on one row and elide cleanly instead of wrapping into the temperature row.
- Quick Actions are single-line rows with a separate right-aligned chevron overlay instead of a two-line subtitle layout.
- Quick Action text and chevrons remain readable at 1280x720, 1600x900 and 1920x1080.
- Recent Games empty-state card is more compact.
- HF33 source-owned runtime, single-owner hardware session, safe launcher and crash recovery remain authoritative.
